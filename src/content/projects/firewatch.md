## Summary

An early-warning platform for wildfire detection. I designed and built the web
platform, then shipped the React Native application — which was the change that
mattered operationally. A detection sitting on a monitor in an office is worth
considerably less than the same detection reaching the person standing near the
fire, and the mobile app is what closed that gap.
